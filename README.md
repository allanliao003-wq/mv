# 《融化的糖》Melting Sugar — 人物 MV

用程式逐格生成的 Neo-Soul / Slow Jam R&B 人物 MV。男女兩位主角以「輪廓光剪影」呈現，畫面隨歌曲段落和 808 / Hi-hat 律動變化。

- 成片：`out/melting_sugar_mv.mp4`（1280×720，24fps，2.39:1 電影遮幅，約 3 分鐘）
- 渲染器：`render_mv.py`（Python + OpenCV + NumPy；每一格只由時間 t 計算，可以平行渲染）
- 音訊：`assets/melting_sugar.mp3`

```bash
pip install opencv-python-headless numpy pillow
python3 render_mv.py --preview 20,50,138   # 輸出靜態預覽圖到 out/preview/
python3 render_mv.py --render              # 輸出完整 MV
```

## 製作手法

- **音訊驅動**：每一格算出低頻起音（808／Kick）、高頻起音（Hi-hat）和 RMS 包絡。副歌的曝光、輪廓光強度、預副歌的「心跳」光暈都跟這些數值同步。
- **輪廓光剪影角色**：角色由多層遮罩組成（輪廓、頭髮、衣服、髮絲高光、耳朵與領口細節）。輪廓光由遮罩沿光源方向的位移差算出，再加上環境光包覆。
- **電影感後製**：光暈（bloom）、柔和的高光壓縮、陰影偏青／高光偏暖的分離色調、暗角、底片顆粒、2.39:1 遮幅、副歌入點的白光閃。
